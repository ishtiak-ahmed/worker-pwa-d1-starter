# Project Context Documentation

This directory contains comprehensive context files defining the architecture, database schema, tech stack guidelines, and feature specifications for the **worker-pwa-d1-starter** project.

## Context Files Directory

1. [Project Overview](project-overview.md): High-level goals, key tech highlights, design principles, and edge deployment targets.
2. [Tech Stack](tech-stack.md): Framework specifications, edge runtime architecture, feature-driven directory layout, and developer CLI commands.
3. [Database Schema](database-schema.md): Drizzle ORM schema for Cloudflare D1 (`users` and `items` tables), D1 edge binding access helper (`getDb()`), and migration workflow.
4. [Features & Starter Modules](features.md): Starter dashboard demo UI, Zustand reactive state template, D1 integration, PWA manifest, and demo removal guide.
